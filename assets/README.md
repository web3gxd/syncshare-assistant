# Исходник логотипа

`logo.png` — утверждённый пользователем логотип с облаком и роботом. Иконки 16, 32, 48, 96 и 128 пикселей находятся в `icons/` и получены уменьшением этого изображения.

Логотип переработан встроенным imagegen из предоставленного пользователем `Untitled.png`. Задача генерации: сохранить облако с внутренним изгибом, отдельную голову робота с антенной и двумя глазами; выровнять пропорции и контуры, использовать мятный символ на тёмно-зелёном непрозрачном фоне без объёма и дополнительных деталей.

Старые варианты и промежуточные изображения в состав проекта не входят.
