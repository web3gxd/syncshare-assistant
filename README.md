# SyncShare — помощник для Chrome

<p><img src="icons/icon-128.png" alt="Логотип SyncShare — помощник" width="112"></p>

**Версия 1.2.3 · Manifest V3 · интерфейс на русском языке**

Панель для уже установленного SyncShare. Работает прямо во вкладке теста РАНХиГС, без консоли и отдельной рабочей вкладки.

## Установка

1. Скачайте ZIP из раздела **Releases** репозитория и распакуйте его в отдельную папку. Если расширение уже установлено, сохраните новые файлы в его папку и нажмите «Обновить» в `chrome://extensions`.
2. Откройте `chrome://extensions` и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите распакованную папку, в которой находится `manifest.json`. При работе из исходников выберите корень репозитория.
4. Убедитесь, что исходное расширение SyncShare включено. Обновите вкладку открытого теста.
5. Настройте диапазон задержки и нажмите «Старт» на панели справа.

[Официальная инструкция Chrome](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked).

## Управление

- «Старт» начинает или возобновляет работу; «Пауза» приостанавливает её; «Стоп» завершает текущий проход.
- Два ползунка задают нижнюю и верхнюю границу случайной задержки: от 0,5 до 30 секунд. По умолчанию 4–6 секунд.
- Прокрутку можно отключить. Свёрнутая панель показывает текущий вопрос, статус и прогресс.
- Значок расширения открывает краткий статус и кнопку раскрытия панели.

## Выбор и восстановление

Радиокнопки: выбирается допустимый вариант с максимальным числом submissions; красные варианты исключаются. При равном максимуме ответ сохраняется как есть.

Поддерживается русский и английский интерфейс SyncShare, включая пункты «Статистика» / `Submissions`, значения true/false и сообщения «Ответов пока нет» / `No answer yet`.

Поддерживаются типы вопросов Moodle `multichoice` и `multichoiceset`.

Чекбоксы: отдельно сравниваются true/false для каждого пункта; возможно несколько выбранных вариантов или ни одного. Если **оба** состояния красные, выбирается состояние с большим числом submissions. При равенстве отметка сохраняется.

Перед чтением статистики расширение ждёт появления видимой волшебной палочки SyncShare у нужного вопроса или чекбокса (до двух минут, ожидание можно остановить). Во время чтения `No answer yet` обнаруживается сразу, без ожидания таймаута статистики.

При `No answer yet` расширение сохраняет снимок всех радиокнопок и чекбоксов страницы и выполняет до двух перезагрузок. После загрузки сверяет страницу, порядок полей, идентификаторы и тексты вариантов; затем восстанавливает и проверяет отметки. При несовпадении останавливается, сохранив снимок. Страница с неподдерживаемыми полями других типов автоматически не перезагружается.

Перед переходом на следующую страницу состояние записывается. На новой странице расширение запускается автоматически и продолжает работу. При ручной перезагрузке также пытается восстановить снимок текущей страницы. Внезапное закрытие браузера или аварийное завершение не гарантируют сохранение самого последнего изменения.

Автоматически закрывается только конкретное предупреждение `SyncShare: Critical Error` об одновременном решении нескольких тестов, не более пяти раз за загрузку страницы. Повторяющуюся причину ошибки нужно устранить вручную, например закрыть другие активные тесты.

**Завершение попытки и окончательная отправка не выполняются.** На последней странице проверьте ответы и завершите тест самостоятельно. Число ответов в разделе `Submissions` отражает статистику SyncShare и не гарантирует правильность ответа.

## Данные и разрешения

Единственное запрашиваемое разрешение — `storage`. Скрипты подключаются только к страницам попытки и обзора теста на `https://lms.ranepa.ru/mod/quiz/`. Расширение не отправляет данные на внешние серверы.

Отчёт, тексты выбранных вариантов и снимки отметок находятся в памяти Chrome (`storage.session`), раздельно по вкладкам и попыткам. Закрытие вкладки очищает её записи. Перезапуск Chrome, отключение или обновление расширения очищают эту память. Настройки задержки, прокрутки и сворачивания хранятся в `storage.local`.

Доступ к закрытым элементам SyncShare осуществляется через [официальный chrome.dom](https://developer.chrome.com/docs/extensions/reference/api/dom). Механизм хранения описан в [документации Chrome](https://developer.chrome.com/docs/extensions/reference/api/storage).

## Проверка исходников

Из этой папки при установленном Node.js:

```text
npm test
```

После изменения файлов нажмите «Обновить» у расширения в `chrome://extensions`, затем обновите страницу теста.

## Оформление

Активный логотип: `assets/logo.png`. Montserrat включён локально в формате WOFF2, с поддержкой кириллицы и переменным начертанием 100–900. Лицензия шрифта: `fonts/OFL.txt`. Источник: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/montserrat). Внешних запросов при использовании шрифта нет.

## Разработка и сборка

Для проверки нужен Node.js 20 или новее; для сборки ZIP — Python 3.10 или новее. Устанавливать npm-зависимости не требуется.

```text
npm test
npm run package
```

ZIP появляется в `dist/`. В него входят файлы расширения, инструкция и лицензия шрифта. Тесты, исходник большого логотипа и служебные файлы GitHub в установочный архив не включаются.

Проверки охватывают выбор радиокнопок и чекбоксов, задержки, ожидание палочки, переходы, восстановление снимков, ограничения перезагрузок, изоляцию вкладок, устаревшие сообщения и состав ресурсов. GitHub Actions запускает их при изменении `main` и в запросах на слияние. Автотесты используют имитацию браузера; они не заменяют проверку установленного расширения с конкретной версией SyncShare.

| `panel.js` | Панель на странице теста |

| `scripts/` | Проверка ресурсов и сборка ZIP |
